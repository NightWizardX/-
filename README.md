# บันทึกรายจ่าย (Expense Tracker)

แอป Android สำหรับจดค่าใช้จ่ายส่วนตัว ใช้งานคนเดียว ข้อมูลเก็บในเครื่อง (ไม่ต้องล็อกอิน ไม่ต้องใช้อินเทอร์เน็ต)

## ฟีเจอร์
- **บันทึกเร็ว** – กดปุ่ม "บันทึกรายจ่าย" → พิมพ์จำนวนเงิน → เลือกหมวด → บันทึก (จำหมวดที่ใช้ล่าสุดให้)
- **อ่านสลิปโอนเงิน** – ไม่ต้องพิมพ์เอง ทำได้ 3 ทาง:
  - กดปุ่มรูปใบเสร็จ (เหนือปุ่ม "บันทึกรายจ่าย") แล้วเลือกรูปสลิปจากแกลเลอรี
  - ในหน้าบันทึก กด "อ่านจากรูปสลิปโอนเงิน"
  - ในแอปธนาคารหรือแกลเลอรี กด "แชร์" สลิป แล้วเลือก "บันทึกรายจ่ายจากสลิป"

  แอปอ่านยอดเงิน วันและเวลา ธนาคาร ชื่อผู้รับ และบันทึกช่วยจำ มาใส่ในฟอร์มให้ ตรวจแล้วกดบันทึก
  - บันทึกช่วยจำบนสลิป (เช่น "ขนม") ลงช่องบันทึกช่วยจำในแอปตรงตามสลิป ถ้าสลิปไม่มี จะใส่ชื่อผู้รับและธนาคารแทน
  - อ่านได้ทั้งสลิปภาษาไทยและอังกฤษ ปี พ.ศ./ค.ศ. เดือนแบบย่อ/เต็ม
  - รู้ว่าเป็นธนาคารไหน (กสิกรไทย ไทยพาณิชย์ กรุงไทย กรุงเทพ กรุงศรี ttb ออมสิน ธ.ก.ส. ฯลฯ) จาก QR บนสลิป
  - เตือนเมื่อมีรายการยอดเท่ากันในเวลาใกล้กันอยู่แล้ว (อาจเป็นสลิปเดิม)
  - เลือกหมวดให้จากรายการก่อนๆ ที่มีบันทึกช่วยจำ (หรือผู้รับ) เดียวกัน เช่น เคยลง "ขนม" ไว้หมวดอาหาร
    สลิปถัดไปที่เขียน "ขนม" ก็จะเป็นหมวดอาหาร
  - ถ้าอ่านวันที่บนสลิปไม่ได้ จะใช้เวลาที่บันทึกรูปสลิปแทน
  - อ่านด้วย OCR ในเครื่อง ไม่ต้องใช้อินเทอร์เน็ต และไม่ส่งรูปออกไปไหน
- **แดชบอร์ด** 5 แบบ: รายวัน / รายสัปดาห์ / รายเดือน / รายปี / ช่วงเวลาที่เลือกเอง
  - ยอดรวม, จำนวนรายการ, ค่าเฉลี่ยต่อวัน (รายปีแสดงต่อเดือน), เทียบกับช่วงก่อนหน้า (▲▼ %)
  - กราฟแท่ง (รายชั่วโมง / รายวัน / รายเดือน) แตะแท่งเพื่อดูยอด
  - กราฟโดนัทแยกตามหมวดหมู่ + % แตะหมวดเพื่อกรองรายการ
  - รายการแยกตามวัน แตะเพื่อแก้ไข/ลบ
  - เลื่อนช่วงก่อน/ถัดไปด้วยลูกศร หรือแตะวันที่เพื่อเลือกจากปฏิทิน
- **ลูกเล่น / motion graphics**
  - ยอดเงินวิ่งนับขึ้น (count-up) ทุกครั้งที่ข้อมูลเปลี่ยน
  - การ์ดสรุปไล่สี มีฟองวงกลมลอยเบาๆ และอีโมจิอารมณ์ตามการใช้จ่าย/งบ (เด้งตอนเปลี่ยน)
  - กราฟแท่งโตขึ้นทีละแท่งแบบเด้ง มีเส้นประค่าเฉลี่ย แตะแท่งแล้วมี tooltip + สั่นเบาๆ
  - กราฟโดนัทหมุนกวาดเข้า แตะชิ้นไหนชิ้นนั้นหนาขึ้น ชิ้นอื่นจางลง ตรงกลางเปลี่ยนเป็นข้อมูลหมวดนั้น
  - แถบสัดส่วนหมวดค่อยๆ เติมไล่กัน, การ์ดและรายการเลื่อนขึ้นมาแบบไล่ลำดับ
  - ปัดซ้าย/ขวาบนแดชบอร์ดเพื่อเปลี่ยนวัน/สัปดาห์/เดือน (ชื่อช่วงเลื่อนตามทิศทาง)
  - ปัดรายการไปทางซ้ายเพื่อลบ พร้อมปุ่ม "เลิกทำ"
  - ปุ่มบันทึกหดเหลือไอคอนเมื่อเลื่อนลง, เปลี่ยนหน้าแบบสไลด์
- **งบประมาณรายเดือน** พร้อมแถบแสดงว่าใช้ไปกี่ % / เกินงบเท่าไร (หน้ารายปีเทียบกับงบ × 12)
- **จัดการหมวดหมู่** เพิ่ม/แก้ไขชื่อ อีโมจิ สี และซ่อนหมวดที่ไม่ใช้
- **สำรองข้อมูล** ส่งออก/นำเข้าไฟล์ CSV (เปิดใน Excel / Google Sheets ได้)
- วันที่แบบไทย (พ.ศ.), รองรับโหมดมืด, ใช้สีตามธีมเครื่อง (Android 12+)

## ติดตั้งบนมือถือ
1. เปิดลิงก์นี้บนมือถือ (ได้ APK เวอร์ชันล่าสุดเสมอ):
   https://github.com/NightWizardX/-/releases/latest/download/expense-tracker.apk
   หรือเข้าหน้า **Releases** ของ repo แล้วดาวน์โหลด `expense-tracker.apk`
2. เปิดไฟล์ APK แล้วอนุญาต "ติดตั้งแอปที่ไม่รู้จัก" ให้เบราว์เซอร์หรือแอปไฟล์
3. อัปเดตเวอร์ชันใหม่: ดาวน์โหลดจากลิงก์เดิมแล้วติดตั้งทับ ข้อมูลไม่หาย
   (ต้องตั้งค่าคีย์เซ็นแอปตามหัวข้อถัดไปก่อน)

ต้องการ Android 8.0 (API 26) ขึ้นไป

## ตั้งค่าคีย์เซ็นแอป (ทำครั้งเดียว)
Android จะยอมติดตั้งทับ (อัปเดต) ก็ต่อเมื่อ APK ใหม่เซ็นด้วยคีย์เดียวกับตัวเดิม
คีย์นี้เป็นความลับและ repo นี้เป็นสาธารณะ จึงเก็บไว้ใน GitHub Secrets ไม่ใช่ในโค้ด

1. ใน repo บน GitHub: **Settings → Secrets and variables → Actions → New repository secret**
2. เพิ่ม 2 ค่า:
   - `SIGNING_KEYSTORE_BASE64` = ไฟล์ keystore (PKCS12) ที่แปลงเป็น base64
   - `SIGNING_PASSWORD` = รหัสผ่านของ keystore
3. แท็บ **Actions → Build APK → Run workflow** เพื่อ build APK ที่เซ็นด้วยคีย์นี้

ถ้ายังไม่ตั้งค่า แอปก็ยัง build ได้ แต่ APK จะเซ็นด้วยคีย์ชั่วคราวคนละอันทุกครั้ง จึงไม่ขึ้นหน้า Releases
(ดาวน์โหลดได้จาก Artifacts ของรันนั้นในแท็บ Actions) และติดตั้งทับเวอร์ชันอื่นไม่ได้ ต้องถอนแอปเก่าก่อน
ซึ่งข้อมูลในแอปจะหาย ให้ **ส่งออก CSV** ไว้ก่อนแล้วนำเข้าหลังติดตั้ง

สร้าง keystore เองได้ด้วย JDK:
```bash
keytool -genkeypair -keystore release.p12 -storetype PKCS12 -alias expense-tracker \
        -keyalg RSA -keysize 4096 -validity 36500 -dname "CN=Expense Tracker"
base64 -w0 release.p12   # คัดลอกผลลัพธ์ไปใส่ SIGNING_KEYSTORE_BASE64
```
เก็บไฟล์ keystore และรหัสผ่านไว้ในที่ปลอดภัย ถ้าทำหาย APK ใหม่จะติดตั้งทับตัวเดิมไม่ได้

## ความปลอดภัยและความเป็นส่วนตัว
- แอปไม่ขอสิทธิ์อินเทอร์เน็ต ข้อมูลไม่ออกจากเครื่อง ยกเว้นตอนที่คุณส่งออก CSV เอง
- อ่านสลิปด้วย OCR และตัวอ่าน QR ในเครื่อง ไม่ขอสิทธิ์อ่านรูปทั้งหมด เข้าถึงได้เฉพาะรูปที่คุณเลือกหรือแชร์มา
  แอปไม่เก็บรูปสลิป เก็บแค่ยอดเงิน วันเวลา และบันทึกช่วยจำที่คุณกดบันทึก
- ข้อมูลอยู่ในพื้นที่ส่วนตัวของแอป แอปอื่นอ่านไม่ได้ ระบบสำรองข้อมูลของ Android
  อาจสำรองไว้ใน Google Drive ของคุณ (เข้ารหัสเมื่อเครื่องตั้งรหัสล็อกหน้าจอไว้)
- ไฟล์ CSV ที่ส่งออกไม่ได้เข้ารหัส เก็บไว้ในที่ที่ไว้ใจได้
- ส่งออก CSV: ช่องที่ขึ้นต้นด้วย `= + - @` จะมี `'` นำหน้า กันสูตรอันตรายทำงานเมื่อเปิดใน Excel/Sheets
  (นำเข้ากลับมาแอปจะตัด `'` ออกให้เอง)
- นำเข้า CSV: จำกัดขนาด 10 MB ตรวจรูปแบบจำนวนเงินอย่างเข้มงวด และจำกัดความยาวข้อความ
- คีย์เซ็นแอปอยู่ใน GitHub Secrets เท่านั้น ไม่อยู่ใน repo

## Build เอง
- **Android Studio:** เปิดโฟลเดอร์นี้แล้วกด Run (ใช้ Gradle ตาม `gradle/wrapper/gradle-wrapper.properties`)
- ไลบรารี OCR (Tesseract4Android) มาจาก JitPack ซึ่งตั้งไว้ใน `settings.gradle.kts` ให้ใช้กับไลบรารีนี้เท่านั้น
- **Command line:** ติดตั้ง Gradle 8.11+ และ Android SDK แล้วรัน
  ```bash
  gradle assembleRelease      # ได้ไฟล์ app/build/outputs/apk/release/app-release.apk
  gradle testReleaseUnitTest  # unit tests
  ```
  ถ้าต้องการ `./gradlew` ให้รัน `gradle wrapper` หนึ่งครั้ง

## โครงสร้างโค้ด
- `data/Models.kt` – โมเดลข้อมูล, ตัวอ่าน/เขียน CSV, การกันสูตรใน CSV
- `data/Repository.kt` – SQLite (ตาราง categories, expenses), การตั้งค่า, ส่งออก/นำเข้า CSV
- `data/Stats.kt` – ช่วงเวลา (วัน/สัปดาห์/เดือน/ปี/ช่วง), การคำนวณสรุป, รูปแบบเงิน/วันที่ไทย
- `data/SlipParser.kt` – แยกยอดเงิน วันเวลา ธนาคาร ผู้รับ บันทึกช่วยจำ จากข้อความ OCR ของสลิป และอ่าน QR สลิป
- `data/SlipReader.kt` – เปิดรูป, อ่าน QR (ZXing), ทำ OCR (Tesseract, ภาษาไทย + อังกฤษ)
- `ui/DashboardScreen.kt` – หน้าแดชบอร์ด
- `ui/EditExpenseScreen.kt` – หน้าบันทึก/แก้ไขรายจ่าย
- `ui/SettingsScreen.kt` – ตั้งค่า งบประมาณ หมวดหมู่ สำรองข้อมูล
- `ui/Components.kt` – ธีม กราฟแท่ง กราฟโดนัท แอนิเมชัน
- `ui/SlipUi.kt` – ปุ่ม/การ์ดผลอ่านสลิป และแอนิเมชันระหว่างอ่าน
- `app/src/main/assets/tessdata/` – ข้อมูลภาษาสำหรับ OCR (ไทย, อังกฤษ)
